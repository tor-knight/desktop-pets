# Desktop Pets (健康提醒小憩)

Desktop Pets 是一款专为 macOS 设计的极简线条风格“桌面宠物”健康提醒应用。它的目标是在你沉浸于工作时，默默在后台守护你的健康，并在你连续工作时间过长时，用温柔而不粗暴的方式强制你休息一下。

## 🌟 核心功能

1. **番茄钟式连续工作判定**
   - 默认设定为 **45分钟** 的连续工作时间。
   - 只要你一直在使用电脑（键盘打字、移动鼠标），顶部系统菜单栏的 🐾 图标旁就会实时显示倒计时。
   - 当倒计时归零时，应用会弹出一个覆盖所有屏幕的半透明蒙层，并播放极简的线条宠物动画，提醒你放下工作。

2. **智能空闲休息判定**
   - 真正的“智能重置”：它不会因为你仅仅停下来看了一会儿屏幕就重置时间。
   - 只有当你**真正离开电脑超过 5 分钟**（没有任何键盘或鼠标输入），系统才会判定你已经完成了休息，并在后台默默将下一个工作周期的时间重置回 45 分钟。

3. **低电量智能降级**
   - 考虑到动画渲染的性能，应用监听了系统的电源状态。
   - 如果你的 Mac 处于**未连接电源且电量低于 20%** 的状态，应用会自动暂停渲染和计时器，绝不浪费你宝贵的电量。

4. **强制蒙层与“逃生舱”机制**
   - 触发休息时，全屏幕会被半透明蒙层覆盖，屏蔽其他窗口的干扰。
   - 考虑到紧急工作情况，蒙层中央提供了一个**“长按 5 秒跳过 (Escape)”** 的逃生舱按钮，长按即可提前结束本次休息。

5. **菜单栏状态与控制**
   - 顶部菜单栏常驻 🐾 图标和实时倒计时，随时掌控你的工作节奏。
   - 点击图标可快速打开设置主界面或退出应用。

## 🛠 编译与打包说明

本项目基于 Swift 5.9+ 和 SwiftUI 开发，目标平台为 macOS 14.0+。你可以使用以下命令行直接在终端进行编译打包：

```bash
# 确保在项目根目录 /Users/didi/workspace/own-proj/desktop-pets 下执行
DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer xcodebuild -project DesktopPets.xcodeproj -scheme DesktopPets -configuration Release CONFIGURATION_BUILD_DIR="$(pwd)/build" clean build
```

编译成功后，打包好的应用程序会输出在当前目录的 `build/DesktopPets.app`。

## ⚠️ 常见问题：关于 macOS 的权限拦截

本应用依赖 macOS 的**“辅助功能 (Accessibility)”**来监听全局的键盘和鼠标事件（用于判定你是否在工作）。由于我们是本地编译的临时签名应用，macOS 安全机制非常严格：

**问题：** 为什么我在系统设置 -> 隐私与安全性 -> 辅助功能 里把 `DesktopPets` 的开关打开了，应用依然提示没有权限？
**原因：** 每次重新编译打包后，应用的底层哈希签名会改变。macOS 会认为这是一个“被篡改的新应用”，从而在底层拦截它，即使界面上的开关是开着的。

**解决办法（必看）：**
1. 打开系统设置 -> 隐私与安全性 -> 辅助功能。
2. 选中列表里的 `DesktopPets`。
3. 点击左下角的 **`-`（减号）**，把它**彻底删除**。
4. 双击打开刚刚重新编译的 `build/DesktopPets.app`。
5. 顺着系统弹窗再次进入辅助功能，打开新出现的 `DesktopPets` 开关。
6. 点击一下 DesktopPets 的应用窗口使其成为前台，界面瞬间就会变为绿色的 `✅ Permissions granted`。
